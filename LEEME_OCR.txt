ACTUALIZACIÓN OCR - LIBRO DE APERTURA (Laravel 9)

REQUISITO:
Este parche se aplica SOBRE el proyecto que ya tiene instalado y funcionando el módulo
Libro de Apertura del parche anterior.

ARCHIVO A REEMPLAZAR:
resources/views/cliente/opening/create.blade.php

PASOS:
1. Haz una copia de seguridad del archivo create.blade.php actual.
2. Extrae este ZIP en la raíz del proyecto Laravel (por ejemplo C:\xampp\htdocs\contaduria).
3. Acepta reemplazar únicamente resources/views/cliente/opening/create.blade.php.
4. Ejecuta: php artisan view:clear
5. Abre Libro de Apertura > Registrar balance inicial.

USO:
- Selecciona una imagen JPG, PNG o WEBP.
- Pulsa "Reconocer fotografía".
- El OCR divide la imagen en dos columnas: izquierda (Activo) y derecha (Pasivo/Capital).
- Los importes reconocidos se colocan en Debe o Haber respectivamente.
- Las cuentas que no se reconozcan quedan sin seleccionar para que el usuario las asigne.
- Revisa y corrige fecha, glosa, cuentas e importes.
- SOLO el botón "Guardar Libro de Apertura" registra los datos.

IMPORTANTE:
- El reconocimiento se ejecuta en el navegador usando Tesseract.js desde CDN.
- Requiere Internet para descargar Tesseract.js y el idioma español la primera vez.
- La imagen no se sube ni se guarda en el servidor por este código.
- No hay migraciones nuevas ni cambios de base de datos.
- El OCR puede equivocarse: revisar siempre los campos antes de guardar.
- El reconocimiento está optimizado para balances parecidos al ejemplo: Activo a la izquierda,
  Pasivo y Capital a la derecha. Si la foto tiene otro diseño, puede requerir ajustes.
